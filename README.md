> **课题名称**：缓冲区页面置换：LRU 与 LFU 对比（存储与索引）
> **面向课程**：《高级数据库系统》大作业 · 动画报告与理论研讨
> **指导要求**：自制 5 分钟左右动画演示，涵盖正常过程、算法边界情形、异常或反例；提交演示文稿（PPT推荐/HTML/视频）、说明书（提示词、讲解稿、组员分工说明）；评分标准：机制正确 40%、动画效果 30%、讲解问答 30%。

## 一、快速开始（组员分发版）

**获取项目**：

```bash
git clone https://github.com/fakerUNcode/db-hw.git
```

**运行演示（三选一，推荐方式一）**：

| 方式 | 平台 | 操作 |
| :--- | :--- | :--- |
| **① 一键脚本（推荐）** | Windows | 进入 `演示文稿` 文件夹，双击 **`start-windows.bat`**，浏览器自动打开演示页 |
| | macOS / Linux | 终端执行 `bash 演示文稿/start-mac-linux.sh`（macOS 可先 `chmod +x` 后双击运行） |
| **② 手动起本地服务** | 全平台 | 在 `演示文稿` 目录执行 `python -m http.server 8642`，再访问 `http://127.0.0.1:8642/index.html` |
| **③ 直接打开** | 全平台 | 用任意现代浏览器直接打开 `演示文稿/index.html`（页面零运行时依赖，断网可用，仅在线字体回退为系统字体） |

- 脚本默认使用端口 `8642`；如端口被占用，可带参数换端口：`start-windows.bat 9000` 或 `bash start-mac-linux.sh 9000`。
- 停止演示：在脚本窗口按 `Ctrl+C`（或直接关闭窗口）。
- 脚本依赖 Python 3（仅用于启动内置 HTTP 服务）；没有 Python 时直接用方式三。

## 二、网页演示操作手册

### 1. 播放控制（三种状态自动切换）

| 按钮文案 | 含义 |
| :--- | :--- |
| **开始演示** | 初始状态 / 演示播完。点击后从第 0 步开始自动推演 |
| **暂停演示** | 播放中显示。点击冻结在当前步 |
| **继续演示** | 中途暂停后显示。点击从当前步继续 |

- **首次进入页面或切换到任意导航页**，演示都会**自动复位为初始状态**（清空缓冲帧、命中率归零），等待点击"开始演示"，讲解时不会出现状态错乱；
- 配合 **上一步 / 下一步 / 重置** 可单步讲解；
- **倍速** 0.5x – 2.0x 实时可调。

### 2. 请求传送带（支持点击跳转）

传送带上每一个页面块都可以**直接点击**，跳转到该步骤并暂停——答辩回放任意一步无需重头再来。

### 3. 自定义请求流压测

控制栏输入框支持自定义引用串（逗号 / 空格 / 中文逗号分隔，如 `P1, P2, P3, P5, P1`），**按 Enter 或点击"载入"**立即生效；输入为空时输入框会抖动提示。同屏竞技页输入后点击"同步运行"即可双引擎对比。

### 4. 两组内置反例（一键注入）

| 按钮 | 模块 | 演示内容 |
| :--- | :--- | :--- |
| 注入全表扫描反例 | LRU | 一次全表扫描污染缓冲池，热点页被驱逐、命中率崩塌 |
| 注入频次僵死反例 | LFU | 历史高频"幽灵页"霸占槽位，新活跃页频遭淘汰 |

### 5. 其他

- **同屏竞技**：LRU 与 LFU 双引擎跑同一请求流，底部实时命中率对决条会为**领先一方**呼吸增亮；
- **深浅主题**：左下角一键切换，选择会被浏览器记忆（localStorage），下次打开自动恢复；
- **键盘可达**：Tab 聚焦导航项后按 Enter / Space 即可跳转（焦点环可见）；系统开启"减弱动态效果"时装饰动画自动收敛。

## 四、常见问题

| 问题 | 解决 |
| :--- | :--- |
| 双击 bat 闪退 / 提示找不到 Python | 安装 [Python 3](https://www.python.org/downloads/)（勾选 Add to PATH），或改用方式③直接打开 index.html |
| 端口 8642 被占用 | 脚本后跟端口参数（如 `start-windows.bat 9000`） |
| 断网环境 | 页面本体 100% 离线可用，仅霞鹜文楷网络字体会回退为系统字体 |
| 打开页面是英文域名地址栏 | 正常，本地服务仅监听 127.0.0.1，不会访问外网 |
| 想恢复默认请求流 | 点击"重置"，或重新载入 `P1, P2, P3, P4, P1, P2, P5, P1` |
