## 二、 详细任务拆解与交付责任清单

### 1. 组长（张同学 - 贡献度 35%）
- **核心定位**：项目总负责人兼现场主讲人，负责整个课题的学术水准与理论高度。
- **具体工作任务**：
  1. **理论形式化与机制建模**：梳理数据库 Buffer Pool 真实运行架构，明确 Page Table、Buffer Frames、Pin Count 引用计数、Dirty Flag 脏页标记与 WAL 协议的约束关系；
  2. **反例数学推导与实验设计**：构造“全表扫描引发 LRU 缓存污染”与“工作集漂移引发 LFU 历史频次僵死”两组极端对比序列，量化命中率对比；
  3. **学术汇报 PPT 编制**：设计并使用自动化脚本生成 16 页 16:9 宽屏学术汇报幻灯片（`lru_lfu_comparison.pptx`），覆盖所有核心章节与演讲备注；
  4. **演讲演练与控时把控**：主导编写《5分钟现场逐字讲解稿》，并组织团队开展多次模拟演练，确保现场演说严格在 5分00秒 完赛；
  5. **全局质量审核**：对照实验要求图中的三维评分标准（机制、动画、问答）进行全流程验收。

### 2. 组员一（李同学 - 贡献度 33%）
- **核心定位**：全栈开发工程师，负责核心交互动画系统与双引擎仿真实现。
- **具体工作任务**：
  1. **双置换引擎算法编码**：
     - 在前端独立实现 LRU 的 $O(1)$ 哈希表 + 双向循环链表逻辑；
     - 攻克 LFU 传统最小堆 $O(\log N)$ 缺陷，实现基于 Ketan Shah 论文的 $O(1)$ 双向频次桶链表 + 桶内节点双链表 + `min_freq` 指针架构；
  2. **交互式 HTML5 仿真平台开发**：
     - 采用原生 HTML5/SVG/CSS3/ES6+ 打造单文件零外部依赖的 `演示文稿/index.html`；
     - 实现物理缓冲槽位（Frames）与底层逻辑数据结构的同屏双重视图联动；
     - 开发单步步进、单步回溯、重置、自定义页面流输入压测功能；
  3. **声画同步旁白与多媒体集成**：
     - 基于 Web Speech API 开发实时语音解说功能，根据算法当前执行步骤动态播报机制原理；
     - 设计 5分钟自动化演示剧本（Auto Tour），实现开箱即用的自动化演练。

### 3. 组员二（王同学 - 贡献度 32%）
- **核心定位**：数据库内核研读者与答辩攻坚专家，负责工业落地对照与答辩防线。
